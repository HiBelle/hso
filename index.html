📲 安裝到手機主畫面（類原生 APP）

請確認您的 GitHub 儲存庫最外層同時放有 index.html 與 questions.csv，開啟網址即可安裝成桌面 APP：

🍎 iPhone (Safari)：
開啟網址 → 點擊底部「分享」按鈕 → 選擇「加入主畫面」→ 點擊「新增」。

🤖 Android (Chrome)：
開啟網址 → 點擊右上角「⋮」選單 → 選擇「加到主畫面」或「安裝應用程式」。

⚙️ CSV 題庫管理（題庫與畫面分離）
